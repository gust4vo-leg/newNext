# newNext 🚀

Bem-vindo ao repositório **newNext**! Este espaço foi criado para organizar e centralizar os projetos e exercícios práticos desenvolvidos durante a minha jornada de aprendizado em desenvolvimento de software.

---

## 📂 Estrutura do Repositório

O repositório está dividido em projetos específicos para facilitar a navegação:

*   **[projeto02](./projeto02):** Aplicação principal focada no desenvolvimento de funcionalidades e componentização (como a recente adição do botão voltar na página de visualização).
*   **[receitas](./receitas):** Exercício prático e lições desenvolvidas durante o curso no **SENAI**.

---

## 🛠️ Tecnologias Utilizadas

Os projetos contidos aqui utilizam o ecossistema de desenvolvimento web moderno:

*   **HTML5 / CSS3** - Estruturação e estilização das páginas.
*   **JavaScript (ES6+)** - Lógica de programação e dinamismo.
*   *Git & GitHub* - Controle de versão e hospedagem do código.

---

## 🚀 Como Executar os Projetos

Para rodar qualquer um dos projetos localmente, siga os passos abaixo:

1. Clone este repositório em sua máquina:
   ```bash
   git clone https://github.com
   ```

2. Navegue até a pasta do projeto desejado:
   ```bash
   cd projeto02
   # ou
   cd receitas
   ```

## 📝 Boas Práticas Adotadas

*   **Conventional Commits:** Organização do histórico de alterações para manter o projeto legível.
*   **Modularização:** Separação de pastas por escopo de aprendizado (projetos vs. lições do SENAI).
